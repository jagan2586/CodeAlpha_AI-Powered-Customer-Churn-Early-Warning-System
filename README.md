# AI-Powered Customer Churn Early Warning System

## 📌 Project Overview
This project predicts customer churn using Machine Learning and identifies high-risk customers so businesses can take proactive actions.

## 📊 Dataset
IBM Telco Customer Churn Dataset (loaded via public URL)

## ⚙️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## 🤖 Model
Random Forest Classifier

## 📈 Features
- Data Cleaning
- Exploratory Data Analysis
- Customer Churn Prediction
- Risk Classification (High / Medium / Low)
- Feature Importance Analysis
- Business Insights

## 🎯 Results
- Accuracy ~ 80%
- ROC-AUC ~ 0.84

## 📌 Business Impact
Helps telecom companies identify customers likely to churn and take retention actions.
